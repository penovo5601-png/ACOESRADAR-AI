# AçõesRadar AI 📈

Avaliação de ações de todos os mercados (só ações) com veredito **SOBE / DESCE**, 15+ indicadores técnicos em confluência, valuation fundamental, **notícias associadas com análise de sentimento** e analisador de **fotos de gráficos** (`/analise-grafico`).

## Deploy na Vercel
1. Importar este repositório em vercel.com/new e clicar **Deploy**.
2. (Opcional) `DATABASE_URL` (PostgreSQL, ex. Neon) para Watchlist e histórico de fotos.
3. (Opcional) `OPENAI_API_KEY` para visão GPT-4o no analisador de gráficos.

Sem variáveis, toda a análise de ações, indicadores, notícias e veredito funcionam na mesma.
